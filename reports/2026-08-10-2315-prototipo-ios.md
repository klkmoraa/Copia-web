# Prototipo iOS aislado de StructureCo

**Fecha:** 2026-08-10 23:15
**Agente:** Codex
**Rama:** main

## Qué cambió

Se completó el prototipo móvil aislado en `prototypes/ios-app/`: splash, acceso
simulado, Inicio, Proyectos, creación en dos pasos, mesa de trabajo, resultados,
tablas y Cuenta/Ajustes. Se añadió un launch local y se guardaron 17 capturas
finales del flujo en claro, oscuro y landscape.

Durante la validación se corrigió el arrastre de la hoja inferior: el asa ahora
inicia el gesto correctamente y no vuelve a ciclar el tamaño al soltar. Los
controles visibles de navegación, filtros, zoom, hoja e interruptores
segmentados tienen cajas táctiles de al menos 44 pt.

## Por qué

El objetivo fue cerrar el nuevo prototipo iPhone sin modificar la aplicación de
producción, manteniendo la identidad Clay de StructureCo y una navegación nativa
con tab bar sólo para Inicio, Proyectos y Cuenta.

## Archivos tocados

- `.claude/launch.json` — añadió el perfil local `ios-prototype` en el puerto 5199.
- `.claude/skills/mobile-app-ui-design/` — skill local usada para el diseño móvil.
- `prototypes/ios-app/` — implementación React/Vite aislada, README y capturas.
- `prototypes/ios-app/src/components/Sheet.tsx` — corrigió drag/snap del bottom sheet.
- `prototypes/ios-app/src/styles/app.css` — ajustó objetivos táctiles a 44 pt.
- `prototypes/ios-app/scripts/screenshots.mjs` — recorrido Playwright con capturas,
  checks de drag, touch targets, scroll, overflow y consola.

## Cómo verificar

```powershell
npm.cmd --prefix prototypes/ios-app run build
npm.cmd --prefix prototypes/ios-app run dev
# En otra terminal, con el servidor arriba:
npm.cmd --prefix prototypes/ios-app run shots
```

El último recorrido generó `01-splash.png` a `17-home-landscape.png` sin errores
de consola.

## Pendiente / siguiente paso

Nada pendiente para el alcance del prototipo. Solver, backend y persistencia
siguen explícitamente simulados y fuera de este alcance.
